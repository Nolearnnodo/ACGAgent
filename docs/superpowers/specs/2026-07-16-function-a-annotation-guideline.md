# 功能 A 古籍知识抽取人工标注操作手册（历史试标版）

> 版本：v0.2.1（试标版）  
> 更新日期：2026-07-22  
> 适用对象：古籍标注员、复核员  
> 标注范围：单篇古籍的文献概况、人物、人物等级、生平事件、历史事件关联、人物关系和原文证据  
> 不标内容：跨文献同名人物辨认、外部史料考证、CBDB 等外部人物资料库核验和人物合并
>
> **已被修订版二取代。** 当前业务规则以 2026-08-22 的《标注规范（修订版二）》为准；本文仅保留历史试标记录，不得用于生成新的标注结论。机器输出格式参见 `docs/superpowers/specs/2026-08-22-ai-extraction-annotation-output-spec.md`。

本手册只回答两件事：**原文中要标什么，以及遇到不同写法时怎样判断。** 标注工具会处理编号、字符位置、保存格式和关系编码，标注员不需要计算或填写这些内容。

## 1. 先弄清这项任务

### 1.1 最终要交出什么

每篇文章要形成一份**完整、能由原文逐条核查的标注结果**，包括：

1. 文献属于哪一类，主人公是否有女性、残损、出家、字或号等特征，文献年号及朝代能否确定；
2. 文中出现了哪些可以确认身份的人物，哪些称谓不应当作人物；
3. 谁是唯一的一级人物，哪些是二级、三级人物；
4. 一级和二级人物有哪些出生、籍贯、死亡、埋葬、任职事实；
5. 人物是否与项目历史事件表中的事件有原文明示的联系；
6. 人物之间有什么原文明示的关系，方向是什么；
7. 每条判断由哪一段标题或正文支持；
8. 哪些地方原文没有说、暂时不能判断，或当前工具无法完整记录。

合格的标注应做到：**不漏原文事实、不添原文没有的事实、人物和事件不张冠李戴、每条事实都有充分证据、疑难处不强猜。**

### 1.2 本任务不做什么

- 不查百科、搜索引擎、CBDB 等外部人物资料库或其他史料；
- 不纠正历史真伪；
- 不判断跨文章的同名者是不是同一人；
- 不手工填写英文字段名、内部编号、字符位置或关系字母；
- 当前工具无法完整记录的原文事实，按“工具暂不支持”处理，不改成错误类别。

### 1.3 六条硬规则

1. **只依据本篇标题和完整原文。** 外部常识不能补进标注结果。
2. **所有适用项目都要检查。** 不能因为原文没有明显答案就直接跳过。
3. **每条事实都要有证据。** 证据要能同时说明“是谁”和“发生了什么”。
4. **没有写就留空，不确定就交复核。** 不能为了填满界面而猜。
5. **逐人、逐类检查。** 每位一级和二级人物都要依次检查五类生平事件，不能只标显眼内容。
6. **原文事实优先于工具限制。** 工具装不下时标“工具暂不支持”，不能把事实硬塞进错误类别。

### 1.4 本手册中的常用说法

| 说法 | 含义 |
| --- | --- |
| 主人公 | 全文主要叙述的人物，如墓主、单人列传的传主 |
| 一级人物 | 主人公；普通单主人公文献有且只有一人 |
| 二级人物 | 与主人公关系紧密、且原文给出明确关系或重要事迹的人物 |
| 三级人物 | 有可识别姓名，但只是一过性出现或缺少实质描述的人物 |
| 原文证据 | 标题或正文中能直接支持一条判断的原样文字 |
| 标准名称表 | 项目提供的年号表、历史事件表等；只用于统一名称，不用于补事实 |
| 篇内补全 | 只依据本篇语法和上下文补足姓名，不是查外部资料 |
| 关键指代 | 为确认人物或事实所需的简称、代称、字、号或官称 |
| 暂不能判断 | 原文残缺、互相矛盾，或存在两种以上合理解释 |
| 工具暂不支持 | 原文事实清楚，但当前标注项目无法无损记录 |

## 2. 一篇文章按什么顺序标

严格按以下顺序可以减少漏标和前后矛盾。

### 第一步：确认材料完整

- 核对标题和正文是否属于同一篇；
- 确认工具显示的是完整正文，不是截断片段；
- 若正文缺页、标题错配、出现明显转换错误，先标记材料问题；
- 标注开始后若原文版本变化，旧标注不能直接沿用。

### 第二步：快速确认文献概况

先判断文献类型、主人公和几个概况项。此时不要急着展开人物事件。

### 第三步：通读全文，圈出人物候选

- 圈出所有可识别的姓名、残缺姓名、氏族称名、法名，以及能明确回指这些人的简称；
- 同时圈出“先考、夫人、府君、诸子”等疑似人物但可能不应建立的称谓；
- 先求完整，不要在第一次通读时遗漏篇末署名、引文和长名单中的人物。

### 第四步：合并同一人，划分人物等级

- 判断全名、简称、字、号、官称是否指同一个人；
- 同名但上下文显示为不同个体时必须拆开；
- 确定一级人物，再逐个判断二级、三级；
- 每个人物都填写一句简短的分级理由。

### 第五步：填写人物信息

记录人物原文姓名、可允许的篇内补全、字、号、称号和关键指代。官职不要混入称号。

### 第六步：逐人检查五类生平事件

只对一级和二级人物逐项检查：

- 出生；
- 籍贯；
- 死亡；
- 埋葬；
- 任职。

每检查完一类，都在工具中选择“已检查且有事实”或“已检查但原文未提及”。这样可避免因某类没有结果而忘记检查。

### 第七步：检查历史事件和人物关系

- 查找人物是否被原文明示为参与、发动、经历或受到某一历史事件影响；
- 查找一级和二级人物之间的亲属、婚姻、师承和其他明确关系；
- 先确认两端人物，再确认“从甲看乙是什么关系”。

### 第八步：证据与完整性复查

- 逐条点开事实，确认所选证据确实支持该事实；
- 确认事件没有归到错误人物；
- 确认没有把文献年号自动抄给所有事件；
- 确认没有用常识补地点上级、姓名、官职或关系；
- 处理所有“暂不能判断”和“工具暂不支持”项后再提交。

## 3. 所有项目共同遵守的判断方法

### 3.1 允许使用的材料

可以使用：

- 本篇标题；
- 本篇完整正文；
- 项目提供的年号标准名称表；
- 项目提供的历史事件标准名称表；
- 本手册中的关系说明。

不能使用：

- 搜索结果、百科、CBDB 等外部人物资料库、论文和其他古籍；
- 个人记忆中的历史知识；
- 同库其他文章对本篇姓名、时间或关系的补充。

标准名称表只能把原文已有的名称统一成项目名称，不能因为表中存在某个事件，就推断人物参加了该事件。

### 3.2 证据怎样选

一条合格证据应满足：

1. **原样**：不得改字、补字、换成白话或删去残缺符号；
2. **够用**：能看出事实属于谁，并能看出事实内容；
3. **尽量短**：通常选一个短语或一句话，但不能为了缩短而删掉主语或关键动作；
4. **位置准确**：直接在标题或正文中框选，由工具记录位置；
5. **允许多段**：若人名在前句、事实在后句，或一条关系必须由两处共同支持，可以选择两段证据。

例如，“宝历初”只能说明时间，不能单独证明任职；“宝历初，以兵部郎中知制诰”才能证明任职内容。若这句话的主语在前句，证据还应包括能确定人物的前句片段。

以下内容不是合格证据：

- 从其他文章复制来的文字；
- 只出现了相同人名但与该事实无关的句子；
- 由年份计算或历史常识得出的结论；
- 改写后的现代汉语概括。

### 3.3 四种特殊状态

| 界面选择 | 什么时候用 | 示例 |
| --- | --- | --- |
| 原文未提及 | 本项可以有，但本文没有写 | 没有写出生日期 |
| 暂不能判断 | 有相关文字，但残缺、冲突或存在多解 | “李□”可能指两人之一 |
| 本项不适用 | 这一类事实本来就不需要该项 | 籍贯事实不需要事件时间 |
| 工具暂不支持 | 事实清楚，但现有项目无法完整表达 | 一次事件同时有出发地和目的地 |

不要把“原文未提及”和“暂不能判断”混用。前者是没有信息，后者是有信息但无法可靠决定。

### 3.4 原文写法与标准名称都要保留

- 人名、字、号、官职、地名和证据保留原文用字；
- 年号和历史事件另选项目标准名称；
- 异体字、繁简字和残缺字不要私自改写；
- 怀疑文字识别错误时保留当前文本，标记“疑似文字错误”，不能静默改字；
- 标题与正文用字不同时分别保留，并交复核判断是否同一对象。

### 3.5 否定、计划和假设不是已发生事实

以下一般不标成生平事件：

- “未尝仕”“不就征”中的未任职；
- “将葬于某地”但后文说明未葬成；
- “若授某官”“当迁某职”等假设或预测；
- 引用古人事迹来比喻主人公，而非叙述主人公本人；
- 只表达愿望、评价、品德或能力的句子。

若句子先否定后明确叙述实际结果，只标实际发生的部分。

### 3.6 原文自相矛盾时不替作者裁定

若同一篇对姓名、时间、地点或亲属关系有互相冲突的记载：

- 分别框选两处证据；
- 标为“暂不能判断”并说明冲突；
- 不用外部知识挑选“更正确”的一条；
- 不把两条冲突信息拼成一个看似完整的事实。

## 4. 文献概况怎样标

### 4.1 文献类型

界面只选择中文类别，不需要记数字。

| 类别 | 常见文献 | 注意 |
| --- | --- | --- |
| 墓志铭或塔铭类 | 墓志、墓志铭、塔铭，以及项目已确认归入本类的材料 | 不能因为正史中写到墓葬就选本类 |
| 一般历史文献 | 正史列传、方志、笔记等 | 不能因为标题含某人墓葬经历就改成墓志类 |

文献类别不在二者中或标题、正文冲突时，选“暂不能判断”并交项目负责人，不自行扩充类别。

### 4.2 主人公概况

| 项目 | 怎样判断 | 常见错误 |
| --- | --- | --- |
| 原文明示主人公为女性 | 标题或正文明确称夫人、妻、女、比丘尼等 | 文中出现任意女性就选“是” |
| 正文含残缺符号 | 完整正文中实际出现 `□` 等项目指定残缺符号 | 只因语义不通就判断残损 |
| 原文明示主人公为出家人 | 主人公被称为僧、尼、道士、法师、禅师等 | 文中出现一位僧人就选“是” |
| 主人公明确出现字或号 | 有“字某”“号某”等明确表达 | 把谥号、庙号、法号直接当作字或号 |

“未明示为女性”不等于“已经证明为男性”。此项只检查原文是否有明确女性依据。

残缺符号可由工具自动检测，标注员只需在工具提示异常时核对全文。

### 4.3 文献级年号是试标项

文献级年号的项目定义尚待最终确认。现阶段按以下顺序处理：

1. 墓志或塔铭优先找原文明示的撰写、立石或成文时间；
2. 若没有上述时间，只有明确下葬时间时，可以选下葬年号，但必须注明依据是“下葬”；
3. 正史列传只有在全文确有一个明显叙事中心年号时才选；
4. 全文跨多个时期且没有唯一中心时，选“暂不能判断”；
5. 没有原文证据时不能为了填满而选一个年号；
6. 选择标准年号时同时核对所属朝代；同名年号跨朝代或在同一朝代重复使用时，只能依据本篇文字区分；
7. 必须同时框选年号证据，并说明选择依据。

例如项目表中存在两个不同的“上元”时，界面应显示各自朝代和帝王时期供选择。本文不能唯一判定时选“暂不能判断”，不要靠个人记忆猜是哪一个。

此项有歧义时交复核，不影响其他人物和事件继续标注。

## 5. 人物怎样识别和分级

### 5.1 哪些内容建立人物

应建立人物：

- 原文出现可以区分个体的姓名；
- 姓名部分残缺但仍能稳定指向一个人，如“李□”；
- “王氏”“陇西李氏”等虽无名、但上下文明确指向一个具体个体的氏族称名；
- 明确指向个体的法名、道号或其他个人名号；
- 后文简称、字、号、谥号或官称能够明确回指已建立人物时，作为该人物的指代，不另建新人。

不建立人物：

- “先考、亡妻、夫人、府君、恩师、友人”等没有姓名或氏族称名的泛称；
- “诸子、群臣、僚属、百姓”等集合；
- 只有“某”或“□”，无法稳定区分个体的残缺称谓；
- 书名、地名、官名或历史事件名称中偶然包含的人名文字；
- 只出现帝号、庙号或官称，必须靠外部知识才能还原个人姓名的称谓；
- 被否定、假设或比喻句带出的虚指人物。

不建立的人物称谓仍可框选到“排除记录”，写明“匿名泛称、集合、名称组成部分、只能外部还原”等原因。这样可以防止复核时反复争论。

若主人公本人只有帝号、官称或严重残缺称谓，导致不能按上述规则建立，应标“工具暂不支持”，不能凭常识补本名，也不能随意另选他人做一级人物。

### 5.2 同一人物何时合并，何时拆开

合并为同一人：

- “李虞仲”“虞仲”“见之”在本篇能明确共指；
- 本名、字、号、谥号和明确官称指向同一人；
- 同一人先后改官称，但上下文连续且身份明确；
- 同一人改名或有曾用名，原文明确说明二者关系。

拆成不同人物：

- 同名但父母、官职、时代或叙事位置表明是两个人；
- 同一称谓在不同段落指向不同人；
- 无法证明两个简称共指时，不要勉强合并，标“暂不能判断”。

跨文章是否同人不在本任务中判断。

### 5.3 人物信息怎样填

| 项目 | 规则 |
| --- | --- |
| 原文姓名 | 本篇最完整、明确的个人称名，保留原文用字，不含“府君、夫人”等纯尊称 |
| 篇内补全姓名 | 只有本篇语法足以无歧义补出时才填，并同时保留原文姓名 |
| 字 | 只记录“字某”明确给出的内容 |
| 号 | 只记录“号某”明确给出的内容；不要和字拼成一个词 |
| 称号 | 封号、谥号、庙号、法号等；纯尊称不记，官职不放这里 |
| 关键指代 | 首次姓名，以及支撑事件或关系判断的简称、字、号、官称等 |
| 分级理由 | 用一句具体说明解释为什么是一级、二级或三级 |

若原文同时有字和号，二者都要保留。当前工具若只能放在同一栏，标“工具暂不支持”，不要擅自删掉一个。

#### 允许的父系篇内补姓

原文写“李虞仲……父端”时，若本篇父系谱系语法清楚且不存在其他合理解释，可以记录：

- 原文姓名：“端”；
- 篇内补全姓名：“李端”；
- 补全理由：“由本篇父系关系无歧义补姓”。

母亲、妻妾、姻亲、收养关系或关系不清者不得照此补姓。原文姓名必须保留，不能把“李端”伪装成原文直接出现的文字。

### 5.4 人物等级的判断顺序

先问三个问题：

1. **全文主要讲谁？** 该人是一级人物。
2. **此人与主人公是否有明确紧密关系，且原文给出了具体关系或重要作用？** 通常是二级人物。
3. **此人是否只被顺带提到、列入名单、用于引典或缺少实质描述？** 通常是三级人物。

| 等级 | 必须满足 | 常见人物 |
| --- | --- | --- |
| 一级 | 全文叙事中心；普通单主人公文献只有一人 | 墓主、单人列传传主 |
| 二级 | 与一级人物有明确紧密关系，且关系本身或相关事迹在原文中有具体证据 | 具名父母、配偶、子女、师父；对主人公生死或仕途有重要作用的人 |
| 三级 | 有可识别姓名，但仅一过性出现，或没有足以说明重要性的具体内容 | 署名者、名单成员、引文人物、仅作年代背景的人物 |

#### 通常直接判二级

- 原文明示且具名的父母、配偶、子女；
- 原文明示且具名的师父、关键弟子；
- 明确导致主人公获救、遇害、重大升迁、贬谪等关键经历的人；
- 与主人公共同构成文章核心叙事的人，但仍能判断主人公主次。

#### 需要结合篇章作用判断

- 兄弟姐妹、祖父母、孙辈：有具体关系或事迹通常为二级；只在长谱系名单中出现可为三级；
- 远祖、远亲：仅列名通常为三级；对主人公身份或事件有实质作用才升二级；
- 君主、上级、同僚、同乡：一次性颁诏、同场或同乡不足以成为二级；有持续关系或关键作用才是二级；
- 撰者、书者：只在篇末署名通常为三级，正文另有重要关系时再判断；
- 仇敌、对手：仅作背景为三级，直接造成主人公重大事件且有具体叙述可为二级。

不能因为某人的相关文字较多就直接提高人物等级，也不能因为某人有官职就自动判二级；仍须判断其与主人公的关系和篇章作用。

### 5.5 三级人物标到什么程度

三级人物只保留：

- 可识别的原文姓名；
- 必要的篇内补全说明；
- 第一次或最能证明身份的证据；
- 三级理由。

三级人物不做五类生平事件主标注，不展开完整属性和历史事件关联。工具若设置“三级扩展项”，可用于补充分析，但不能和一级、二级主结果混在一起。

### 5.6 多人合传、夫妻合葬怎么办

若两人确实并列为全文中心，不能为了满足“一级唯一”随意挑一人：

1. 优先由数据管理员拆成两篇独立标注任务；
2. 无法拆分时标“多人并列主人公”；
3. 保留各自事实和证据；
4. 交复核员和项目负责人处理，不纳入普通文献的一级唯一性检查。

## 6. 生平事件怎样标

### 6.1 总规则

主任务只标一级和二级人物。每条事件都应能回答：

- 是谁；
- 发生了哪一类事情；
- 原文怎么说；
- 有什么明确时间、地点或官职；
- 证据在哪里。

不要把普通行为、品德评价、文学创作、疾病、婚姻、迁居、科举、受封、战斗等硬塞进五类事件。原文确有重要事实但不属于五类时，记入“工具暂不支持的事实”。

### 6.2 五类事件

| 类型 | 应标内容 | 不要误标 |
| --- | --- | --- |
| 出生 | 明示“生、诞”等出生事实，以及明确出生时间或地点 | “某地人”通常是籍贯；不能由享年和卒年倒算生年 |
| 籍贯 | “某州某县人”“其先某地人”等籍贯或祖籍表达 | 任职地、居住地、死亡地、墓地 |
| 死亡 | 卒、薨、没、终、遇害等明确死亡事实 | 下葬日不是死亡日；只有享年而无死亡语境时应谨慎复核 |
| 埋葬 | 葬、窆、迁葬、祔葬等实际发生的埋葬事实 | 墓志出土地、计划墓地、死亡地点 |
| 任职 | 授、拜、迁、转、出为、知、领、任，以及明确陈述某人担任某官 | 科举资格、品德、普通任务；不同任职不要挤成一条 |

籍贯事件没有“发生时间”，工具中应选“本项不适用”，不能把文献年号填进去。

### 6.3 一条还是多条事件

基本单位是“一人、一次、一个事件类型”。

| 原文写法 | 怎样标 |
| --- | --- |
| “授甲官，后迁乙官” | 两条任职事件 |
| “历甲官、乙官、丙官” | 通常三条任职事件 |
| “拜甲官兼乙职” | 若表示同一次任命，保留为一条完整复合官职 |
| “卒于某地，明年葬某地” | 一条死亡、一条埋葬 |
| 同一任职在文首、文末重复 | 一条事件，允许附两处证据 |
| “初葬甲地，后迁葬乙地” | 两条埋葬事件，并说明迁葬 |
| 同一时间统辖连续两次任职 | 两条事件都可引用该时间证据 |

若无法判断复合官衔是一项还是多项任职，标“暂不能判断”，不要凭现代官制常识拆分。

### 6.4 事件属于谁

事件证据必须能确定人物。尤其注意：

- “其父为太常少卿”是父亲的任职，不是主人公的；
- 连续叙述换了主语后，后面的卒、葬、授官不能继续归给前一人；
- “诏以某为刺史”中，被任命者才是任职人物；
- 引文中的古人事迹不能记到引用者身上；
- 一段中多人同名时，必须依据最近明确主语和上下文判断。

若动作句没有人名，需要前文才能确定主语，可同时选择前文人物证据和动作句证据。

### 6.5 时间

标注时间时先框选完整原文表达，再填写能明确判断的部分。

- 年号、年、月、日只填原文明示或由同一句时间状语明确统辖的内容；
- 不把文献级年号自动复制给每条事件；
- 不以 0 或其他数字表示未知；没有写就选“原文未提及”；
- “明年、翌年、其冬、后数载”等保留原文，不自行换算为具体年号或公元年；
- “开元二十年”可选择标准年号“开元”，年号内年份为二十；
- 公元年换算由工具或项目标准表处理，标注员不心算；
- 月、日按原文记录，不擅自换成公历日期；
- 一个时间短语明确统辖多个并列事件时，可让每条事件引用同一证据；
- 时间作用范围不清时，标“暂不能判断”。

### 6.6 地点

只记录原文明示的地名和层级：

- 道；
- 府；
- 州；
- 郡；
- 县；
- 乡、里、坊、寺、山、原、墓地别称等其他地点。

注意：

- 原文只写“华州”，不能外推所属道、府、县；
- 原文只写“长安”且仅凭本文不能判断层级时，可放“其他地点”并标待复核；
- “华州刺史”中的“华州”是原文明示地点，可以作为该任职的地点；
- 官职中的地点和实际赴任地点有冲突时，不替原文调和；
- 同一事件同时出现出发地、经过地和目的地，而工具无法区分地点作用时，保留全部证据并标“工具暂不支持”；
- 原文没有地点时，整项选择“原文未提及”，不从官制或历史地图补全。

### 6.7 官职

- 尽量保留完整官职，不随意删掉“行、守、试、检校、知、兼、赠”等限定词；
- “拜甲兼乙”若是同一次任命，可保留完整复合官职；
- “授甲，迁乙”必须拆成两次任职；
- “进士、明经、宏辞”等考试或资格通常不是官职；
- “父李彦，太常少卿”虽没有“授、拜”，仍明确陈述李彦担任该官，可标任职；
- 标题中的官衔只有明确属于该人物时才能使用，并把标题作为证据；
- 追赠事实暂放在任职类，但必须保留“赠”字并注明“追赠”，不能写成生前实际任职；
- 只有任职事件填写官职，出生、籍贯、死亡和埋葬不带官职。

### 6.8 当前五类之外的事实

以下事实可能很重要，但当前不要强行归入五类：

- 婚姻、纳妾；
- 科举中第、入学、受业；
- 迁居、流放、出使；
- 疾病、受伤；
- 著书、作诗、立功、战斗；
- 受封、赐名、改名；
- 普通交往、评价和品德。

工具有“其他原文事实”栏时可保留；没有时标“工具暂不支持”。这些事实不能因为无法入类就消失，也不能污染五类事件。

## 7. 人物与历史事件怎样标

只有同时满足以下四条，才建立人物与历史事件的联系：

1. 原文确实写到了一个具体历史事件；
2. 该事件能对应项目历史事件标准名称表；
3. 原文明示该人物参与、发动、经历、受到影响，或与事件有其他具体联系；
4. 有证据能同时支持人物、事件和二者的联系。

关系说明不超过 15 字，并且要短而明确，例如“参与平叛、因乱避难、发动政变、受战乱波及”。

不要这样标：

- 某人生活在安史之乱期间，就标其参与安史之乱；
- 某人死于 756 年，就标其受安史之乱影响；
- 项目历史事件表中某事件时间与人物任职时间重叠，就自动建立联系；
- 原文只提到事件名，却没有说明这个人与事件的关系。

原文明示的事件不在标准名称表时，记录原文事件名并选择“名称表外事件”，不要硬改成最相近的事件。

历史事件名称中包含的人名文字，不代表正文实际提到了该人物。例如只出现“安史之乱”时，不因此另建“安禄山”或“史思明”人物。

## 8. 人物关系怎样标

### 8.1 先确定两端和方向

主任务只标一级、二级人物之间的关系。关系两端必须是已经建立的具名或可识别人物。匿名“先考、亡妻、恩师”不能成为关系端点。

每次都把关系读成一句话：

> **从甲看，乙是甲的什么人？**

例如原文“李虞仲，父李端”：

- 从李虞仲看，李端是父亲；
- 从李端看，李虞仲是儿子或女儿，必须依据原文能否确认李虞仲性别；
- 不能把“父亲”方向写反。

标注工具应自动生成反向关系。标注员仍要读一遍正向和反向中文，确认二者一致。

### 8.2 关系类别

| 从甲看乙 | 反向通常是 | 使用条件 |
| --- | --- | --- |
| 父亲 | 儿子或女儿 | 乙是甲之父 |
| 母亲 | 儿子或女儿 | 乙是甲之母 |
| 儿子 | 父亲或母亲 | 乙是甲之子 |
| 女儿 | 父亲或母亲 | 乙是甲之女 |
| 丈夫 | 妻子或妾 | 乙是甲之夫 |
| 妻子 | 丈夫 | 乙是甲之妻 |
| 妾 | 丈夫 | 乙是甲之妾 |
| 同父或同母的兄弟姐妹 | 同类关系 | 原文能确认同父或同母 |
| 项目所称“非同父或同母的兄弟姐妹” | 同类关系 | 当前定义待最终确认，不能凭常识猜 |
| 其他关系 | 其他关系 | 师徒、同僚、仇敌等不能用前述关系表达的明示关系 |

人物性别无法确认时，不要为了生成反向关系猜“儿子”或“女儿”，应标“暂不能判断”。

### 8.3 直接关系和多步关系

- 原文明示父、母、子、女、夫、妻等时，优先标最直接的一步关系；
- 原文明示“舅、从兄”等复合亲属关系时，可按工具的中文步骤选择关系链；
- 关系链最长三步；超过三步或无法准确表达时，选“其他关系”并写不超过 15 字的说明；
- 不要根据全篇所有亲属边推导出完整亲属网络；只有原文直接说出复合关系，或同一谱系句明确支持时才标；
- 若中间具名人物也已建立，优先分别标原文明示的直接关系，避免重复制造远距离关系；
- 同一人物对存在多种关系时，先保留最直接、最明确的一种，其他关系记“工具暂不支持的多重关系”。

“其他关系”的说明必须写清方向。例如：

- 甲看乙：“乙为甲师”；
- 乙看甲：“甲为乙弟子”。

非对称关系不能把同一句说明原样复制到两个方向。

### 8.4 关系证据

证据必须支持两端人物和关系本身：

- “父李彦”可支持主人公与李彦的父子关系；
- 只有“李彦”不能支持父子关系；
- 两处谱系文字共同支持一条复合关系时，可以选择两段证据；
- 同姓、同乡、同官、同时出现不能自动推出亲属关系；
- “友人某”若“某”有可识别姓名，可标其他关系“友人”；没有姓名则不能建立人物关系。

三级人物关系如项目需要，可在单独的“三级扩展”中记录，不进入一级、二级主结果。

## 9. 常见疑难情况

| 情况 | 应怎样处理 |
| --- | --- |
| “先考尝为县令”，全文无父亲姓名 | 不建立父亲人物，不建立关系；记录匿名泛称 |
| “夫人王氏”明确指一个人 | 可建立“王氏”人物，不补其个人名 |
| “父端”，主人公明确姓李 | 可按第 5.3 节保留原文“端”，另记篇内补全“李端” |
| 只写“太宗”，必须靠常识还原本名 | 当前不建立本名人物，记排除项；若他是主人公则标“工具暂不支持” |
| 同篇有两个“王安” | 先按上下文分别建立；无法判断某次提及属于谁时标不确定 |
| 人名含 `□` | 保留残缺字；能稳定区分个体则建人物并标不确定，不能区分则不建 |
| 标题有完整姓名，正文只用简称 | 可合并，标题作为姓名证据，正文简称作为关键指代 |
| 标题和正文姓名冲突 | 两处都保留并交复核，不自行改正 |
| 真正多人合传或夫妻并列合葬 | 优先拆分；不能拆时标多人并列，不强选一级 |
| 原文有两种卒年 | 保留两处证据并标冲突，不查外部资料裁定 |
| “出为华州刺史” | 标任职；官职保留“华州刺史”，地点可标“华州”，不补上级行政区 |
| “进士及第，授校书郎” | 进士及第不作官职事件；“授校书郎”作任职事件 |
| “赠吏部尚书” | 暂作任职类并明确标“追赠”，不能写成生前任职 |
| “大历二年卒，明年葬” | 卒年可填大历二年；葬年保留“明年”，不自行换算大历三年 |
| 人物时间落在某历史事件期间 | 没有原文明示联系就不标人物与该历史事件的关系 |
| 原文事实不属于五类生平事件 | 放“其他原文事实”或标“工具暂不支持”，不硬塞类别 |

## 10. 完整示例

以下为专门编写的示例，不作为历史事实来源。

### 10.1 标题和原文

标题：“李承传”

原文：

> 李承，字敬之，京兆府万年县人。父李彦，太常少卿。开元二十年，授华州司功参军；天宝三载，迁监察御史。天宝十四载，安史之乱起，承扈从入蜀。大历二年卒于成都府，明年葬万年县洪原。子李允。

### 10.2 文献概况

- 文献类型：一般历史文献，证据为标题“李承传”；
- 主人公：李承；
- 主人公字或号：明确有字“敬之”；
- 残损：正文没有指定残缺符号；
- 文献级年号：正文跨开元、天宝、大历，不选唯一年号，标“暂不能判断”。

### 10.3 人物

| 人物 | 等级 | 信息 | 分级理由 |
| --- | --- | --- | --- |
| 李承 | 一级 | 字敬之 | 单人列传传主、全文叙事中心 |
| 李彦 | 二级 | 李承之父 | 关系明确，且有官职信息 |
| 李允 | 二级 | 李承之子 | 具名直系亲属，关系明确 |

不另建“安禄山”或“史思明”，因为原文只出现历史事件名称“安史之乱”，没有实际写出二人的姓名。

### 10.4 生平事件

| 所属人物 | 类型 | 时间 | 地点 | 官职 | 主要证据 |
| --- | --- | --- | --- | --- | --- |
| 李承 | 籍贯 | 本项不适用 | 京兆府、万年县 | 无 | “京兆府万年县人” |
| 李承 | 任职 | 开元二十年 | 华州 | 华州司功参军 | “开元二十年，授华州司功参军” |
| 李承 | 任职 | 天宝三载 | 原文未提及 | 监察御史 | “天宝三载，迁监察御史” |
| 李承 | 死亡 | 大历二年 | 成都府 | 无 | “大历二年卒于成都府” |
| 李承 | 埋葬 | 原文“明年”，不换算 | 万年县、洪原 | 无 | “明年葬万年县洪原” |
| 李彦 | 任职 | 原文未提及 | 原文未提及 | 太常少卿 | “父李彦，太常少卿” |

不标李承出生事件，因为原文只有籍贯，没有出生表述。不为李允添加事件，因为原文没有写。

### 10.5 历史事件

若项目标准名称表包含“安史之乱”，可建立：

- 人物：李承；
- 历史事件：安史之乱；
- 关系说明：因乱扈从；
- 证据：“安史之乱起，承扈从入蜀”。

这里有原文明示的人物行为，不是仅凭年份重叠推断。

### 10.6 人物关系

- 从李承看李彦：父亲；反向由工具结合李承性别处理，若仅凭本文无法可靠判断则交复核；
- 从李承看李允：儿子；反向需判断李承是父亲还是母亲，不能仅凭姓名猜；
- 每条关系分别使用“父李彦”“子李允”作证据。

此例特意保留性别反向的不确定性，用来说明：即使关系本身明确，也不能为填满反向项而猜人物性别。

## 11. 怎样确保标注完整

### 三遍覆盖检查

第一遍按人物查：

- 全文所有可识别人物是否都进入人物清单；
- 同一人是否被误拆；
- 同名不同人是否被误合；
- 一级人物是否正确且唯一；
- 二级人物是否有明确理由。

第二遍按事件查：

- 对每位一级和二级人物分别检查出生、籍贯、死亡、埋葬、任职；
- 每个“授、拜、迁、转、知、领、赠”等词附近是否有遗漏任职；
- 每个“卒、薨、没、终、葬、窆、迁葬”等词附近是否有遗漏或归错人；
- 同一时间是否统辖了多个事件；
- 长文后半部分和篇末是否已经检查。

第三遍按关系和证据查：

- 每个具名父母、配偶、子女和师承是否已判断人物等级及关系；
- 每条关系方向能否读成通顺的“从甲看乙”；
- 每条事件证据是否同时支持人物和动作；
- 有没有由同姓、同地、同官或年代重叠产生的猜测；
- 所有不确定和工具限制是否有说明。

这些提示字只帮助寻找候选，不能代替逐句阅读。例如“授、拜”有助于发现任职，但不是出现这些字就一定建立事件，仍要结合语义判断。
